# FURIA Chatbot

Webchat interativo para fãs da FURIA Esports (CS:GO)

## Funcionalidades

- Consulta do elenco atual
- Próximos jogos
- Últimos resultados
- Interação com a comunidade

## Como Usar

1. Digite suas perguntas no chat
2. Use os botões rápidos para consultas comuns

## Tecnologias

- HTML5, CSS3, JavaScript, Node.Js, Express
- Hospedagem: LOCAL
